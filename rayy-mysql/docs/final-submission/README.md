# ملفات التسليم النهائي – مشروع ري (Rayy)

| الملف | الوصف |
|---|---|
| `التقرير النهائي - ري.docx` | التقرير النهائي على قالب الكلية: الأقسام الأربعة كاملة، المخططات، الكود البرمجي كاملاً، الاختبار، دليل الاستخدام، المراجع |
| `نموذج (4) تسليم التقرير النهائي والفيديو - ري.docx` | نموذج (4) معبأ |
| `بوستر المشروع - ري.pptx` | البوستر التعريفي على قالب الكلية (خط Almarai) |
| `العرض النهائي - ري.pptx` | عرض المناقشة النهائية (19 شريحة مع ملاحظات المتحدثة لكل شريحة) |
| `الفيديو التعريفي - ري.mp4` | الفيديو التعريفي (88 ثانية، 1080p، موسيقى ونغمات الجهاز وعناوين عربية) |
| `نص التعليق الصوتي للفيديو - ري.docx` | نص يُقرأ إذا أراد الفريق إضافة صوت إحدى المتدربات على الفيديو |

## ما يكمله الفريق قبل التسليم

* الأرقام الأكاديمية الناقصة (لمياء، وجدان، هدى) في التقرير ونموذج (4).
* جوال القائدة والبريد الإلكتروني (التقرير: آلية التواصل، والبوستر).
* رابط ملفات المشروع وصورة QR Code (التقرير ونموذج 4).
* الصور المؤطرة بخط متقطع 📷 في التقرير: phpMyAdmin، لوحة XAMPP، صور الجهاز الفعلي والتجربة.
* علامات ☐ لاختبارات الجهاز في خطة الاختبار بعد تجربتها، ونتائج الاستبانة لثلاثة مستخدمين.
* عند فتح التقرير في Word اختاري **نعم** لتحديث الحقول حتى يتحدث جدول المحتويات بأرقام الصفحات، ثم احفظي نسخة PDF.
